1. list - впорядкована послідовність об'єктів яка є muttable, аби визначити (я зрозумів це як створення) пустий список достатньо написати list1 = [] (список складається з 0 об'єктів)
2. .append(obj) / .insert(index, obj), де перший додає новий елемент в кінець, а другий додає за вказаним індексом.
3. .pop(index) / .remove(obj), де перший видаляє за індексом, а другий за першим збігом вказаного елементу.
4. list1[index], де: -len(list1) <= index <= len(list1) - 1.
5. list1[n:x], n - індекс початку зрізу (включаючи), x - індекс кінця зрізу (не включаючи).
6. tuple - впорядкована послідовність елементів, яка є immutable. Так як він immutable навідмінну від list, він повністю статичний та не змінюється.
7. dict1 = {
    key: value
}
key - ключ (любий об'єкт який підтримує хешування), value - значення. Його робота дуже крута, так як за допомогою хеш-ключів швидкість отримання значення за ключем моментальна.
Він є впорядкованим, так що підтримує ітерування (тобто можна по ньому пройтись циклом, базово отримавши ключі).
8. Додавання банальне: dict1[new_key] = new_value;
Видалення: dict1.popitem() - видаляє останню додану пару
9. dict[key], важливао що індексації тут немає
10. set - невпорядкована НЕ послідовність, а колекція УНІКАЛЬНИХ елементів (індексація не підтримується), є mutable, тобто змінна.
11. add(obj), remove(obj) - ті самі принципи що й у list.
Є ще метод discard(obj), його різниця міє remove в тому що якщо елемент не був знайдений для видалення, discard не викине помилку, в той час коли remove її викине.
12. if element in set1, тут за це відповідає оператор in.
13. def my_func(), def - ключове слово для визначення функції, після якого йде довільна назва функції.
14. def my_func(x, y) - вказали доступні параметри/аргументи (x та y), my_func(2, 5)/my_func(x = 2, y = 5). 
15. В тілі функції пишем return value, після чого функція перериває свою роботу.
16. Лямбда функції - це ті самі функції, проте без прикріпленого імені (зазвичай вони використовуються, аби зайвий раз не створювати повноцінну функцію, якщо вона буде використана 1 раз у коді)
Приклад: second_degree = lambda n: n**2, second_degree(3), тут назва змінної виступає назвою функції.
17. Так як вони вбудовані, достатньо просто вказати їх назву: len(list1), sum(set1),..
18. new_list = [element**2 for element in list1] - тут ми створюємо новий список, у якому ми розпаковуємо елементи попереднього, та множимо їх самі на себе (зведення до 2-го степеню)
