1. Python - це високорівнева, інтерпритована мова програмування, з широким вибором застосуванням,
вона використовується у : Web, Backend, AI, Data Science, та у багатьох інших задачах.
2. Python володіє простим синтаксисом та одним з найбільших кам'юніті, з багатьма бібліотеками.
3. Основна поточна версія - це 3, яка натомість від 2, має підтримку unicode рядків,
та виправляє низку недоліків попередника.
4. Простими словами, віртуальне середовище - це місце де зберігаються пакети, версія Python-у додатку,
воно потрібне аби розподіляти пакети та версії між додатками, аби все не заважало один одному. 
5. python -m venv .venv (замість .venv, можна використати любу іншу назву).
6. venv, conda.
7. Змінна - посилання на комірку пам'яті у якій зберігається її значення, яке прикрите нормальною
назвою, а не номером комірки. Вони використовується для запам'ятовування значень, для їх подальшого
воикористання (зміна, вивід, тощо).
8. a = 0, де 'а' - назва, 0 - значення, між ними знак присвоєння (=). Потрібно дотримуватись
стандартів PEP8 (тобто нормально називати змінну, щоб не тільки ви знали, що воно таке),
зокрема використовувати snake_case.
9. val = 1 - присвоєння. Змінити змінну можна, знову ж таки, використавши присвоєння: val = 255.
10. print(val) / print(f"{val}"). print() - вбудована функція, що виводить те що всередині.
11. str, int, float, bool та колекції (list, touple, dict, set)
12. type(x) - перевіряє тип об'єкта x (x - ваш об'єкт).
13. Їх як таких у Python немає. За PEP8 ми позначаємо об'єкти які не можна зміювати, великими літерами.
SOME_CONST = 123.
14. a += 1 або a = a + 1, де '+' можна замінити на '-', '/', '*'.
15. flag = True/False, вони використовуються в умовних операторах if, elif, else.
16. Через форматовану стрічку: f"{a} + 1 = {a + 1}".
17. Вони є immutable (незмінні), підтримують індексацію.
18. Коментарі позначаються через символ '#', після нього інтерпритатор ігнорує подальший код/текст.
19. Коли потрібно запам'ятати результат для подальшої роботи, зміни, виведенню.
